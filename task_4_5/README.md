# Задания 4-5: Бенчмарки и покрытие тестами

## Цель
Научиться писать тесты, измерять производительность с помощью бенчмарков и анализировать покрытие кода тестами.

## Структура пакета mathutils

Пакет содержит 4 функции:
- `Fibonacci(n int) (int, error)` - вычисление числа Фибоначчи
- `FibonacciRecursive(n int) (int, error)` - рекурсивная версия, для сравнения
- `IsPrime(n int) bool` - проверка числа на простоту
- `SortAndDeduplicate(nums []int) []int` - сортировка и удаление дубликатов
- `Average(nums []float64) (float64, error)` - среднее арифметическое

## Тесты

### Табличные тесты
Для каждой функции написаны табличные тесты (table-driven tests), покрывающие:
- Граничные случаи (пустые срезы, отрицательные числа)
- Обычные случаи
- Ошибки

## Покрытие кода

```bash
go test -coverprofile=coverage.out
go tool cover -func=coverage.out
```
